# Markdown Style

- Use `*` for bullet points (not `-`)
- Single `#` per file
- Blank line after `##` and `###`
- No numbered lists in headings or lists
- Use native Markdown structures only (no `**label**: description` pseudo-definitions)
- Space between half-width and Japanese characters
- Use half-width parentheses `()`
- Use `**bold**` sparingly
